# 구현 계획

1. 현재 아이콘·메타데이터 변경을 기준 커밋으로 분리한다. 완료
2. 인생 문장과 영화 대사 데이터 및 날짜 선택 로직을 추가한다. 완료
3. 오늘의 문장 카드를 두 영역으로 개편한다. 완료
4. 공유 대표 이미지를 연결하고 OG/Twitter 메타데이터를 추가한다. 완료
5. Hyper-SOAP 프로모션 이미지와 안전 고지가 포함된 데모 CTA를 진료영어 아래에 배치한다. 완료
6. 데이터, 린트, 타입, 빌드, 반응형 화면, 메타 태그, 외부 링크를 검증한다. 완료
7. 기능 커밋 후 `main`에 배포하고 운영 사이트를 확인한다. 완료
8. Hyper-SOAP·HyperLive 카드에 검증된 Microsoft Store·Google Play 설치 링크와 플랫폼 표식을 추가하고 production을 확인한다. 완료
9. 광고를 임시 숨기고, 관리자 맞춤 익명 투표·영구 집계·실시간 원형 그래프를 연결한다. 완료
10. Hyper-SOAP Google Play 승인에 맞춰 양쪽 스토어 설치 카드로 갱신하고 투표와 함께 운영 검증한다. 완료
