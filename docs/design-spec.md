# 데일리 브리핑 디자인 명세

## Direction

- 기존 `max-w-md` 모바일 카드 흐름과 HyperDoctor teal 계열을 유지한다.
- 오늘의 한마디는 차분한 teal, 영화 명대사는 따뜻한 amber 배경으로 감정적 리듬을 구분한다.
- Hyper-SOAP는 deep navy, teal, ivory, restrained gold의 임상 워크스페이스 카드로 다른 정보 카드와 구분한다.

## Components

### 오늘의 문장 카드

- 상단: 중앙 정렬 인생 문장, 자체 문장은 인물 인용과 혼동되지 않도록 `개원의 정석 편집 문장`으로 표기
- 하단: amber 분리 영역, 영화 유형·연도, 짧은 명대사, 작품명, 문장의 맥락을 짚는 `오늘의 울림`
- 긴 문장은 자연스럽게 줄바꿈하고 고정 높이를 사용하지 않는다.

### 공유 이미지

- 아침빛, 브리핑 보드, 펜을 중심으로 한 HyperDoctor 루트의 기존 대표 자산을 재사용한다.
- 이미지 자체에 작은 글자를 넣지 않고 OG 제목·설명과 함께 의미를 완성한다.

### Hyper-SOAP 카드

- 대화 파형이 4영역 기록으로 정리되는 이미지
- `DEMO` 상태, 한 문장 가치 제안, 4개 기능 칩, 전체 폭 CTA, 의료진 검토 고지
- 이미지에는 사람·환자정보·실제 진단·처방을 표시하지 않는다.

## Responsive and accessibility

- 320px 이상에서 가로 스크롤이 생기지 않아야 한다.
- CTA는 최소 44px 높이, 명확한 `focus-visible` 링을 제공한다.
- 이미지에는 기능을 설명하는 대체 텍스트를 제공한다.
- 색상만으로 DEMO나 경고를 전달하지 않고 텍스트를 병행한다.
- 장식적 모션은 추가하지 않아 `prefers-reduced-motion`에서도 동일한 정보가 유지된다.

## States

- 정적 문장 데이터는 빌드 시 필수이므로 빈 상태를 허용하지 않는다.
- Hyper-SOAP는 외부 링크이므로 새 탭·`noopener noreferrer`를 사용한다.
- 공유 이미지와 SOAP 이미지는 로컬 자산으로 배포해 외부 이미지 장애를 피한다.
