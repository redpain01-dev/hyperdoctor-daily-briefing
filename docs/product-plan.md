# 개원의 정석 데일리 브리핑 제품 계획

## Identity

- 포트폴리오 번호: 없음. HyperDoctor 25개 앱을 연결하는 운영 브리핑 서비스
- 이름: 개원의 정석 데일리 브리핑
- 도메인: `briefing.hyperdoctor.app`
- 약속: 개원의에게 필요한 아침 정보와 한 문장의 여유를 한 화면에 전달한다.
- HyperDoctor 관계: 독립적으로 읽을 수 있는 데일리 발행물이면서 관련 실무 도구로 이어지는 관문이다.

## Users and problem

- 주요 사용자: 개원의 정석 카카오톡 커뮤니티의 개원의 및 의료인
- 문제: 날씨, 시장, 행정, 의료뉴스, 저널을 여러 곳에서 확인해야 하며 긴 목록은 아침에 부담스럽다.
- 이번 개선의 계기: 성공과 전진만 반복하는 오늘의 한마디, 공유 이미지 부재, Hyper-SOAP 발견 경로 부재
- 성공 기준: 자체 편집·고전 출처 문장 330개와 선별 영화 대사 80개가 전체 풀을 고르게 순환하고, 출처가 확인되는 한마디에는 저자·작품이 표시되며, 명대사의 울림이 짧게 설명되고 카카오 공유 시 대표 이미지가 노출되며 진료영어 아래에서 Hyper-SOAP 데모로 이동할 수 있다.
- 실패 신호: 반복 문구, 잘못된 작품 귀속, 공유 메타데이터 누락, 동작하지 않는 SOAP 링크

## Scope

### Primary journey

1. 사용자가 카카오톡 공유 카드의 이미지와 제목을 보고 브리핑을 연다.
2. 오늘의 인생 문장과 영화 명대사를 읽는다.
3. 기존 날씨·시장·달력·뉴스·저널·진료영어를 확인한다.
4. 필요하면 Hyper-SOAP 소개를 보고 공개 데모 랜딩으로 이동한다.

### Must

- 철학·관계·쉼·상실·감사·돌봄을 고르게 담은 오늘의 한마디 풀과 출처 정책(확인 가능: 저자·작품, 자체 편집: 데일리 브리핑)
- 작품명과 연도, 문장의 맥락을 짚는 `오늘의 울림`이 표시되는 오늘의 영화 명대사
- Open Graph/Twitter 공유 이미지 및 절대 URL 메타데이터
- Hyper-SOAP 소개 이미지, 기능 요약, 데모 연결, 의료진 검토 고지

### Should

- 한마디와 영화 대사의 순환 주기를 서로 다르게 유지
- 모바일 한 화면에서 각 코너의 정보 위계와 터치 영역 보장
- UTM으로 Hyper-SOAP 유입 경로 구분

### Later

- 사용자가 문장 주제를 선택하거나 저장하는 기능
- 공유 카드의 일자별 동적 문구
- Hyper-SOAP 데모 전용 경로가 생기면 CTA를 해당 경로로 교체

### Non-goals

- 영화 전체 대본 제공
- Hyper-SOAP 기능을 브리핑 내부에 직접 내장
- 환자정보 수집 또는 AI 결과의 자동 차트 반영

## Information and system design

- 인생 문장과 영화 대사는 정적 JSON이며 KST 연중 일차로 선택한다.
- 해외 영화 대사는 짧은 한국어 번역으로 소개하며 작품명과 연도를 표시한다.
- 공유 이미지는 정적 자산이며 Next.js Metadata API가 절대 Open Graph URL을 생성한다.
- Hyper-SOAP는 `soap.hyperdoctor.app` 공개 랜딩으로 새 탭 연결하고 UTM을 붙인다.
- GitHub Actions가 정적 사이트를 매일 다시 빌드·배포한다.

## Safety and trust

- Hyper-SOAP 결과는 진료기록 초안이며 실제 반영 전 의료진 검토가 필요하다는 문구를 CTA 바로 아래 표시한다.
- 프로모션 이미지에는 환자, 개인정보, 진단명, 처방 내용을 넣지 않는다.
- 명대사는 짧은 인용만 사용하고 작품을 명시한다. 번역은 배급판에 따라 달라질 수 있다.
- 외부 도구 장애 시 브리핑의 다른 기능은 계속 읽을 수 있어야 한다.

## Delivery

- 기존 Next.js 정적 export 구조를 유지한다.
- 테스트: JSON 파싱·중복, TypeScript, ESLint, 프로덕션 빌드, 모바일/데스크톱 시각 검수, OG 태그, 외부 링크 확인
- 사용자 요청 자체를 이번 유지보수 범위의 기능 승인으로 간주한다.

## 2026-09-24 HyperLive 연결

- 승인 범위: 오늘의 7분 시장 브리핑 바로 아래, Hyper-SOAP 위에 하이퍼라이브 의료 통역 소개 카드와 공개 앱 연결 버튼을 추가하고 운영 배포한다.
- 실제 공개 앱에서 확인한 실시간 통역, 원문·한국어 나란히 보기, 환자 QR 연결 기능과 공식 아이콘을 사용한다. CTA는 `https://hyperlive.hyperdoctor.app/`에 브리핑 유입 UTM을 붙여 새 탭으로 연다.
- 기존 관리자 코너 스키마를 유지하며 `clinical-english` 묶음에 시장 브리핑 다음으로 추가한다. 해당 묶음의 숨김·이동 설정은 세 카드에 함께 적용된다.
- 별도 통역 기능·환자정보 수집은 추가하지 않는다. Google 로그인 필요 안내와 중요한 진료 내용 확인 문구를 둔다.
- 완료 기준: 빌드 성공, 시장 브리핑 → HyperLive → SOAP 순서, 모바일 화면·이미지·CTA 및 운영 URL 확인.

## 2026-10-26 스토어 설치 카드 업그레이드

- 승인 범위: 기존 Hyper-SOAP·HyperLive 소개 카드에서 앱 설치 가능 여부를 가장 먼저 인지하도록 스토어 등록 배지와 직접 설치 버튼을 추가하고 production에 배포한다.
- Hyper-SOAP는 Microsoft Store Windows 앱 등록을 강조하고, HyperLive는 Microsoft Store Windows 앱과 Google Play Android 앱 등록을 함께 강조한다.
- 각 설치 버튼은 확인된 공식 상세 페이지로 새 탭 연결한다. 기존 웹 앱 CTA는 설치가 어려운 환경을 위한 보조 동선으로 유지한다.
- Windows 및 Google Play 표식은 장식 아이콘으로 처리하고, 링크에는 스토어명·제품명·새 창 정보를 포함한 접근 가능한 이름을 제공한다.
- 설치 이후에도 기존 로그인·이용권 조건과 의료진 확인 책임은 유지하며, 스토어 등록을 임상 정확성 보증으로 표현하지 않는다.
- 완료 기준: 세 스토어 URL 응답·앱명 일치, production build, 375px 모바일 카드·버튼·로고 표시, 공개 production 페이지와 외부 링크 확인.

## 2026-10-28 익명 투표

- 광고 코너는 숨김으로 전환하고 추후 관리자 코너 설정에서 다시 표시할 수 있게 보존한다. 익명 투표는 광고 위치 바로 위에 독립적으로 표시한다.
- 관리자는 기존 Google 관리자 로그인으로 질문·설명·2~10개 선택지·단일/복수 선택·최대 선택 수·한국시간 시작/마감·공개 여부를 편집한다.
- 첫 투표는 AI 구독 종류(ChatGPT, 클로드, 제미나이, 그록, 기타)이며 기본 복수 선택이다. 실제 공개일인 2026-10-29를 기준으로 2026-11-05 23:59 KST에 마감한다.
- 구독자는 로그인 없이 투표하고, 저장 성공 직후 원형 그래프와 득표 수를 확인한다. 화면이 보이는 동안 10초마다 공동 집계를 갱신한다.
- 투표 데이터에는 이름·이메일·IP를 저장하지 않는다. 브라우저에 생성한 임의 토큰의 투표별 해시로 중복을 제한하며 브라우저 변경·저장소 초기화까지 막는 본인인증 투표는 범위 밖이다.
- 서버 시각으로 기간과 선택 수를 검사하고, 데이터베이스 트랜잭션과 고유키로 동시 요청·재시도 중복을 막는다. 관리자 편집 충돌은 revision으로 감지한다.
- 응답이 생긴 질문·선택지·선택 방식 변경은 새 투표로 작성하도록 제한한다. 관리자는 개별 투표자의 식별값 없이 합계만 조회한다.
- 완료 기준: 관리자 생성/편집 → 공개 참여 → 즉시 결과 → 새로고침/다른 브라우저 반영, 비로그인 관리자 거절, 중복·기간 종료·잘못된 선택 거절, 모바일 그래프·접근성 검증.

## 2026-10-29 Hyper-SOAP Google Play 승인 반영

- 승인 범위: Hyper-SOAP 공식 Google Play 설치 링크와 로고·등록 배지를 추가하고 Windows·Android 설치 가능 문구로 기존 카드를 갱신한다.
- 공식 앱 `하이퍼솝 - AI 진료 차팅`의 패키지는 `app.hyperdoctor.hypersoap`이다. 기존 Microsoft Store 버튼, 웹 진입 링크와 의료진 검토 고지를 유지한다.
- 사용자가 승인한 기존 `hyperread-db` 내 전용 스키마 연결과 첫 투표 공개를 함께 완료하고 운영 페이지에서 확인한다.
